# 🎓 資格・検定トラッカー

取りたい資格や検定をリスト化し、**目標スコア**と**受験記録**を管理できる Web アプリです。

インストール不要・ビルド不要。HTML / CSS / JavaScript だけで動きます。

👉 **[デモを開く](https://KURU77.github.io/cert-tracker/)**

---

## できること

| 機能 | 説明 |
| --- | --- |
| 資格リスト | 資格・検定名、カテゴリ、優先度、ステータス（検討中／勉強中／申込済／合格／不合格）を登録 |
| **検索して自動入力** | 資格名を入力すると**約1,400件**のプリセットから候補を表示。選ぶとカテゴリ・目標スコア・満点・受験料・公式サイトが自動で入ります。「ぼき」「boki」「簿記 2」「英検 準1」のように、かな・ローマ字・スペース区切りでも引けます |
| 目標スコア | 目標スコア・満点・単位（点／級／% など）を設定。合否のみの資格にも対応 |
| 受験記録 | 受験日ごとにスコアと合否を記録。最高スコアと目標達成率が自動で計算されます |
| 進捗バー | 「現在の最高スコア ÷ 目標スコア」を可視化。目標到達で緑色に変化 |
| 試験日カウントダウン | 試験予定日までの残り日数を表示。30日以内は強調表示 |
| 検索・絞り込み・並び替え | 資格名／メモの検索、ステータス・カテゴリでの絞り込み、優先度・試験日・達成率などで並び替え |
| **合格で分ける** | 「すべて／挑戦中／合格済み」で切り替え。「すべて」では合格済みを下にまとめて見出しで区切ります |
| **短縮表示モード** | 長い正式名称を通称に置き換えた一覧表示（「実用英語技能検定 準1級」→「英検準1級」）。カードも詰めて表示され、高さはおよそ半分になります |
| 受験料メモ | 受験料や公式サイトURLも記録できます |
| バックアップ | JSON での書き出し／読み込みに対応。端末の乗り換えもかんたん |
| ダークモード | システム設定に追従。ボタンで手動切り替えも可能 |
| スマホ最適化 | iPhone 想定。入力欄は 16px 以上にしてあるので、文字入力で画面が勝手に拡大しません |
| ホーム画面アプリ | 専用アイコンと Web App Manifest を同梱。ホーム画面に追加すると、Safari のアドレスバーなしの全画面アプリとして起動します |

> プリセットの目標スコアは合格ライン相当の**目安**です。受験料や合格基準は変更されることがあるので、実際に申し込む前に公式サイトで確認してください。

## ホーム画面に追加する

iPhone の Safari で[デモページ](https://KURU77.github.io/cert-tracker/)を開き、共有ボタン → **「ホーム画面に追加」** を選ぶだけです。学帽アイコンが並び、タップするとアドレスバーのない全画面アプリとして起動します。

アイコンは `assets/icon.svg` が原本で、そこから各サイズの PNG を書き出しています。

| ファイル | 用途 |
| --- | --- |
| `assets/apple-touch-icon.png` (180px) | iOS のホーム画面アイコン。角丸は iOS 側が付けるので、原本は正方形のまま |
| `assets/icon-192.png` / `icon-512.png` | Android・デスクトップ PWA 用 |
| `assets/icon-maskable-512.png` | Android の丸型・角丸マスク用。図柄を中央 70% に収め、端が切られても欠けません |
| `assets/favicon-32.png` / `icon.svg` | ブラウザのタブアイコン |

> ⚠️ **iOS ではホーム画面アプリと Safari でデータが別々に保存されます。** Safari 側で登録した内容はホーム画面アプリには引き継がれません。移すときは Safari 側で「JSONで書き出し」→ ホーム画面アプリ側で「JSONを読み込み」してください。以後はどちらか一方に絞って使うのがおすすめです。

アイコンを描き直したいときは `assets/icon.svg` と `assets/icon-maskable.svg` を編集し、次のコマンドで PNG を書き出し直します。

```bash
npm install sharp && node tools/generate-icons.mjs
```

## データの保存場所

入力したデータは**ブラウザの localStorage にのみ**保存されます。サーバーへの送信は一切ありません。

- 同じブラウザ・同じ端末でのみデータが見えます
- ブラウザのデータを消去すると、登録内容も消えます
- 別の端末に移すときは、メニュー（⋯）から「JSONで書き出し」→ 移行先で「JSONを読み込み」

## 使い方

### そのままブラウザで使う

[デモページ](https://KURU77.github.io/cert-tracker/)を開くだけです。ブックマークしておけば次回もデータが残ります。

### ローカルで動かす

```bash
git clone https://github.com/KURU77/cert-tracker.git
```

クローンした `index.html` をブラウザで開けば動きます。ローカルサーバーを使う場合は次のいずれかで。

```bash
python -m http.server 8000
```

```bash
npx serve
```

## ファイル構成

```
cert-tracker/
├── index.html       # 画面のマークアップ（フォームは <dialog> で実装）
├── css/style.css    # CSS カスタムプロパティによるライト／ダークテーマ
├── js/presets.js    # 資格・検定のプリセット約1,400件（自動入力の元データ）
├── js/app.js        # 状態管理・描画・localStorage 永続化・候補検索
├── sw.js            # Service Worker（オフライン起動）
├── manifest.webmanifest
├── assets/          # アイコン（SVG 原本と各サイズの PNG）
└── tools/           # アイコン書き出しスクリプト
```

プリセットを増やしたいときは `js/presets.js` に 1 行足すだけです。`alias` には検索用のかな・ローマ字・略称をスペース区切りで書きます。

```js
{ name: '〇〇検定2級', short: '〇〇2級', alias: 'まるまる marumaru 略称', category: 'その他',
  scoreType: 'score', targetScore: 70, maxScore: 100, scoreUnit: '点',
  fee: 5000, url: 'https://…', memo: '合格基準のメモ' },
```

`short` は短縮表示モードで使う通称です。省略した場合は、括弧書きと末尾の「試験」を機械的に削って表示します。

依存ライブラリはありません。すべて素の HTML / CSS / JavaScript です。

## データ形式

書き出される JSON は、次のオブジェクトの配列です。

```json
[
  {
    "id": "…",
    "name": "TOEIC L&R",
    "category": "語学",
    "priority": "high",
    "status": "studying",
    "scoreType": "score",
    "targetScore": 800,
    "maxScore": 990,
    "scoreUnit": "点",
    "examDate": "2026-09-13",
    "fee": 7810,
    "url": "https://www.iibc-global.org/toeic.html",
    "memo": "公式問題集を1冊ずつ。",
    "attempts": [
      { "id": "…", "date": "2026-06-21", "score": 745, "result": "", "note": "Part5が課題" }
    ],
    "createdAt": 1770000000000,
    "updatedAt": 1770000000000
  }
]
```

`scoreType` は `score`（スコアで評価）または `pass`（合否のみ）。`result` は `passed` / `failed` / 空文字です。

## ブラウザ対応

`<dialog>`、`replaceChildren`、`color-mix()` を使っています。Chrome / Edge / Firefox / Safari の最近のバージョンで動作します。
